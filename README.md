# OPLUS盒子

面向 ColorOS 17 的系统增强工具，包名 `com.daxiaamu.oplusbox`。支持 OPPO、一加、真我对应系统，使用现代 Xposed API 102，界面复用设备上的 ColorOS 系统组件。

## 功能

### 系统增强

- **解除实况时长限制**：相册导出实况照片时允许选择更长视频。
- **应用跳转永久允许**：在应用互相调用的系统授权界面增加“永久允许”。
- **简化文件管理授权**：移除文件管理授权的额外确认弹窗。
- **显示“禁用系统优化”**：让中文系统的开发者选项显示此开关；不会替你开启该开关或开发者选项。
- **升级掉 ROOT 提醒**：系统更新完成后，仅在重启将切换槽位时，提醒确认是否已安装 ROOT 到另一个槽位。
- **强制启用本地安装**：始终显示并启用系统更新中的本地安装入口。

### 网络增强

五项功能独立控制：

- 使热点流量经过 VPN。
- 使蓝牙网络共享流量经过 VPN。
- 使 USB 网络共享流量经过 VPN。
- 使以太网络共享流量经过 VPN。
- 使分身应用流量经过 VPN。

通过 ROOT 即时调整对应流量规则，模块负责重启后的恢复。网络共享功能需要手机连接提供虚拟网卡的 VPN；以太网功能用于向其他设备共享网络。不同设备、VPN 客户端与共享方式的实际兼容性需要实机确认。

### 系统工具

- **系统降级**：查询并下载适配本机的官方降级包，支持后台下载、通知进度、暂停与恢复，然后交给系统安装流程。
- **增强型本地安装**：选择官方全量包或降级包，尽量解除系统原有限制。本应用不会、也无法判断安装包是否适配，请自行确认并备份数据。
- **提取系统更新包**：读取已检测更新的版本及下载链接。
- **关闭系统更新**：禁止相关服务联网，开启时通过 ROOT 即时处理，模块负责持续生效；关闭时恢复联网。
- **激活 Google 服务**：安装 Google Play 商店。
- **动画与模糊调节**：动画效果等级、平台动画等级、窗口模糊等级、窗口背景模糊、实时材质模糊。
- **重启菜单**：系统、恢复模式、bootloader、EDL，以及热重启。

### 信息与设置

- 查看设备型号、Android 版本、系统版本、内核版本、安全更新、系统槽位、ROOT 授权及模块激活状态。
- 自动检查更新；有 ROOT 授权时支持 ROOT 自更新。
- 支持暗色模式，采用 ColorOS 原生组件、浮岛底栏及分组列表。

## 使用

1. 安装 APK。本应用当前以 ColorOS 17 为适配目标。
2. 在支持现代 Xposed API 102 的框架中激活模块，并按功能授予 ROOT 权限。
3. 应用会根据功能同步作用域；首次加载模块或新增系统进程作用域时，按框架要求重启对应进程或设备。
4. 按需开启功能。降级包可能自动格式化，全量包跨版本安装也可能需要格式化，请先备份数据。
